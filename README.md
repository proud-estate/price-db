# คลังราคาสินค้าฝ่ายจัดซื้อ

เว็บสำหรับเจ้าหน้าที่จัดซื้อ ใช้บันทึกและเทียบราคาสินค้าของแต่ละร้านค้า พร้อมข้อมูลร้านและเงื่อนไขการชำระเงิน

- ตัวเว็บ: ไฟล์ `index.html` ไฟล์เดียว เปิดผ่าน GitHub Pages
- ระบบล็อกอินและฐานข้อมูล: Supabase (โปรเจกต์ proud-estate-saas, ตาราง `pd_quotes`, `pd_suppliers`, `pd_staff`)
- จัดการพนักงาน: Edge Function `pd-admin-users` (เรียกได้เฉพาะแอดมิน)

## สิทธิ์ผู้ใช้

| สิทธิ์ | ทำอะไรได้ |
|---|---|
| แอดมิน | ทุกอย่าง รวมถึงเพิ่มพนักงาน เปลี่ยนสิทธิ์ ตั้งรหัสผ่านใหม่ ลบราคาและร้านค้า |
| พนักงาน | ดู เพิ่ม แก้ราคาและข้อมูลร้าน ลบได้เฉพาะราคาที่ตัวเองบันทึก |
| ระงับ | เข้าระบบไม่ได้ |

คีย์ที่อยู่ใน `index.html` เป็น anon key ของ Supabase ซึ่งเปิดเผยได้ ข้อมูลถูกป้องกันด้วย Row Level Security ในฐานข้อมูล
